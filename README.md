# Aleksander Wojkowski - Frontend

My personal React project.

## Technologies

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Athena

## Requirements

- Node.js 24
- Yarn 1.22

## Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Go to the project directory:

cd frontend-repository

Install dependencies:

yarn install

## Running the project

yarn dev

Application runs at:

http://localhost:5173
